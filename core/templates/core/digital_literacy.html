Course Modules

MODULE 1: Introduction to Computers & Digital Literacy

  • What is a computer? Types and uses
  • Basic parts of a computer: monitor, CPU, keyboard, mouse
  • Introduction to digital devices (smartphones, tablets, etc.)
  • Importance of digital literacy in today’s world
  • Mini Practice: Identify and name parts of a computer system

MODULE 2: Getting Started – Powering, Navigating & Settings

  • Turning a computer on/off properly
  • Understanding the desktop, taskbar, and start menu
  • Using the mouse: click, double-click, right-click
  • Personalizing settings (wallpaper, date/time, brightness)
  • Mini Practice: Customize desktop background and create a folder

MODULE 3: File and Folder Management

  • Creating, renaming, copying, moving, deleting files/folders
  • Understanding file types (.docx, .pdf, .jpg, etc.)
  • Using flash drives and external storage
  • Mini Practice: Create a folder structure and organize files

MODULE 14: Practical Application & Final Project

  • Using digital tools for communication and collaboration
  • Typing practice and keyboard shortcuts
  • Creating a professional digital profile (LinkedIn basics)
  • Final Mini Project: Submit a digital report using Word, Excel, PowerPoint
